# Crookedlinedesign
2D seimic crooked line design
## 一、输入文件格式要求

程序需要三个数据文件，放在程序目录下（或在 App 中填绝对路径）：

| 文件 | 内容 | 格式要求 |
|---|---|---|
| `Crookedline-Receivers.csv` | 检波点 | 带表头表格，表头须含 `X`、`Y` 列（其余列如 Lin/Stn/Pnt/Elev 可保留，程序只取 X、Y） |
| `Crookedline-Shots.csv` | 炮点 | 同上，表头须含 `X`、`Y` 列 |
| `Crooked line23 CMP.txt` | 初始 CMP 线 | 无表头纯数值，2 列 `X Y`（若第 1 列为常数线号，程序自动取第 3、4 列） |

说明：

- 坐标单位：米。
- 读入后程序自动按 X 升序排序；检波点点号 = 排序后的行号（从 1 开始）。
- 检波点/炮点文件的坐标列名必须是 `X`、`Y`（大小写不敏感），否则按纯数值文件解析前两列。
- CMP 线文件若为多列且第 1 列为常数（线号），自动取第 3、4 列作为 X、Y；否则取前两列。

## 二、主要可设置参数

### 1. 配对方式

| 参数 | 取值 | 说明 |
|---|---|---|
| 配对方式 | 按最大偏移距 / 滚进滚出 | 按最大偏移距：反演半径=maxoffset/2、正演=maxoffset；滚进滚出：反演=noff/2、正演=noff，并按有效段裁剪 |

### 2. 偏移距

| 参数 | 默认 | 说明 |
|---|---|---|
| 最大炮检距设定 noff (m) | 2000 | 滚进滚出模式的反演/正演半径基准 |
| 理论最大炮检距 maxoffset (m) | 4000 | 按最大偏移距配对时的半径基准 |

### 3. 面元

| 参数 | 默认 | 说明 |
|---|---|---|
| 面元X (m) | 12.5 | 面元沿测线**全宽**；半宽=6.25，面元步长=12.5（无缝拼接） |
| 面元Y (m, 空格分隔) | 300 600 | 面元垂直测线**全宽**，可填多个对比；半宽=150/300 |

### 4. 检波点距

| 参数 | 默认 | 说明 |
|---|---|---|
| 检波点距 rint (m) | 25 | 最终检波点等弧长加密步长 |

### 5. 拟合次数范围

| 参数 | 默认 | 说明 |
|---|---|---|
| 检波次数范围 (最小 最大) | 2 6 | 检波线每段多项式次数搜索范围，程序按残差自动选 |
| CMP次数范围 (最小 最大) | 2 6 | CMP 线每段多项式次数搜索范围，自动选 |

### 6. 断点

| 参数 | 默认 | 说明 |
|---|---|---|
| 断点个数 | 1 | 范围 1~5；位置由程序自动确定（趋势剧变点） |
| 断点数据源 | 炮点 / CMP线 | 用炮点或 CMP 线找趋势剧变点 |
| 容差 窗口 | 100 1500 | 断点容差(m) 与拟合窗口/重叠点数 |

### 7. 检波点范围（可选）

| 参数 | 默认 | 说明 |
|---|---|---|
| 点号起 / 点号止 | 留空 | 检波点点号范围（排序后序号）；留空=全部；起止需同时填或同时留空。炮点、CMP 不裁剪 |

### 8. 迭代

| 参数 | 默认 | 说明 |
|---|---|---|
| 迭代次数上限 | 5 | 迭代对比时扫描的最大次数 |
| 最终迭代次数 | 3 | 对比后选定，点"应用"生效 |

## 三、建议的运行步骤（App）

1. **启动程序**，确认三个输入文件路径。
2. **点"加载并显示"** → 在"点位查看"页签查看检波点/炮点/CMP 点位；鼠标悬停可看点号与坐标。
3. **（可选）填检波点点号范围**：根据点位图确定要用的检波点区间，填"点号起/点号止"；留空则用全部。
4. **选配对方式**：按最大偏移距或滚进滚出。
5. **设断点**：填断点个数（1~5），选断点数据源（炮点/CMP线）。
6. **设次数范围与面元**：检波/CMP 次数范围（默认 2 6）、面元 X/Y 全宽、检波点距。
7. **迭代对比**：填"迭代次数上限"，点"迭代对比"，看偏差收敛与覆盖曲线，选"最终迭代次数"，点"应用"。
8. **点"运行"**：生成测线图、覆盖对比图、覆盖统计表、新老CMP偏差图。
9. **导出**：点"导出检波点（优化后）"，选路径保存 CSV（PointNo, X, Y）。
